# 🎲 Smart Dice Rolling Simulator

A Python-based Interactive CLI (Command Line Interface) Tool designed to simulate rolling customized dice, tracking outcomes, and calculating statistical summaries.

---

## Project Overview & Objective

The primary objective of this project is to strengthen foundational core Python programming concepts through a practical, interactive mini-project. 

### Key Features:
- **Customizable Dice & Rolls:** Users can specify the number of dice sides and total roll attempts.
- **Statistical Summary:** Automatically computes the **Total Sum** and **Average** of the rolled outcomes.
- **Interactive CLI Menu:** Includes replay functionality (`y/n`) and built-in user guidance (`help`).
- **Input Formatting:** Utilizes clean Python string formatting for clear output presentation.

---

## Python Concepts Applied

- **Control Flow:** `while` loops for continuous game flow and conditional statements (if-else).
- **Data Structures:** Python `List` for storing rolled values dynamically.
- **Built-in Functions:** `sum()`, `len()`, `range()`, and `input()`.
- **Randomization:** Python `random` module (`randint`) for generating unpredictable dice results.
- **Functions:** Modular code structure using Python `def` functions.
